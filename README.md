# 9Game – Mobile Game Portal

React 기반의 모바일 미니게임 포털입니다. (벽돌깨기, 미로찾기, 워터링, 스네이크, 플래닛 보블, 수박 게임 …)  
자이로스코프 / 터치 / 마우스로 조작하는 게임들을 한 곳에서 즐길 수 있습니다.
휴대폰(안드로이드 크롬)의 자이로스코프로 하는 조작에 가장 최적화 되어 있습니다.

## PWA / 오프라인
`vite-plugin-pwa`(Workbox)를 통해 앱 셸(홈 화면·공용 라이브러리·아이콘)만 빌드 시 Precache합니다.  
게임 모듈(`assets/games/**`)과 게임 자산(`games/**`)은 Precache에서 제외되어, 게임을 처음 열 때 다운로드된 뒤
런타임 캐시(`game-modules`: CacheFirst, `game-assets`: StaleWhileRevalidate)에 저장되어 이후 오프라인에서도 실행됩니다.
(한 번도 열지 않은 게임은 오프라인에서 실행할 수 없습니다.)  
Google Fonts(Press Start 2P)는 CacheFirst 전략으로 1년간 오프라인 캐시됩니다.  
모바일 홈 화면에 추가하면 전체화면 앱으로 실행됩니다.

## 벽돌깨기 (Brick Breaker)

고전 브레이크아웃. 패들로 공을 튕겨 벽돌을 모두 깨면 스테이지 클리어입니다. 외부 물리 엔진 없이 AABB 충돌로 구현했고, 화면은 9 × 16 논리 좌표계를 DOM 레이어로 투영합니다.

- **조작**: 휴대폰을 좌우로 기울인 각도만큼 패들이 움직입니다(수평계 방식, ±25°면 양 끝). 센서가 없으면 터치/마우스의 가로 위치로 패들을 직접 옮깁니다
- **모드**: Classic(7 × 8 격자, 5스테이지), Twelve(동물 그림 타일 6 × 4, 5스테이지). Twelve의 타일은 1~12단계 동물이고, 단계가 높을수록 단단합니다(1~6타). 스테이지가 올라갈수록 높은 단계가 자주 나옵니다
- **벽돌 (Classic)**: 일반, 단단한 벽돌(3타), 강철(파괴 불가), 폭탄(주변 연쇄 파괴), 숨은 벽돌(첫 타격에 드러나고 두 번째에 파괴), 4스테이지부터 좌우로 움직이는 벽돌
- **아이템 (8초)**: 🔥 관통 공, ↔ 패들 확대, ⚪ 공 2개 추가, ⚡ 레이저(10발), 🧲 자석 / 방해 아이템: ↕ 패들 축소, 💨 공 가속, 🐢 공 감속
- **점수**: 벽돌을 연속으로 깰수록 콤보 배율이 올라가고 패들에 닿으면 초기화됩니다. 공이 2개 이상이면 점수 2배. 벽돌을 깨면 피버 게이지가 차고, 가득 차면 6초간 피버(관통 + 점수 2배). 클리어 보너스 = 시간 보너스 (120 − 경과 초) × 50 + 남은 목숨 × 1,000 + 노미스 클리어 시 +5,000
- **목숨 / 별**: 목숨 3개. 별은 클리어 · 목숨 잃지 않기 · 목표 시간 내 클리어로 3개이며, 여러 판에 걸쳐 모읍니다. 스테이지별 최고 점수와 별은 로컬에 저장됩니다

## 미로찾기 (Maze Escape)

휴대폰을 기울여 공을 굴려 미로를 빠져나가는 게임입니다. 화면이 공을 따라 움직입니다.

- **조작**: 휴대폰을 기울인 방향과 각도대로 공이 굴러갑니다(약 14°면 최대 가속). 권한이 필요한 브라우저(iOS 등)는 시작할 때 센서 권한을 요청하고, 센서가 없으면 키보드 방향키로 조작합니다
- **스테이지**: 9스테이지. 1~8은 시드가 고정되어 매번 같은 미로가 나오므로, 길을 외워 기록을 줄이는 재미가 있습니다. 마지막 9스테이지(Infinite Forge)는 판마다 새로 생성됩니다. 미로 크기는 7 × 10칸에서 18 × 28칸까지 커집니다
- **장애물 / 요소**: 구멍(빠지면 마지막 체크포인트로 돌아감), 체크포인트 2개(정답 경로 1/3 · 2/3 지점), 포탈(3스테이지부터, 지름길로 순간이동), 순환 경로와 가운데에 구멍이 있는 빈 방
- **별 3개**: 클리어 + 코인 3개 모두 수집 + 한 번도 구멍에 빠지지 않기. 스테이지별 최고 별과 상위 3개 기록(시간)을 로컬에 저장합니다

## 워터링 (Water Ring)

90년대 물고리 게임기 복각. 버튼으로 물살을 쏴서 링을 기둥에 끼웁니다.

- **화면**: 가로(landscape) 전용. 화면 전체가 물탱크이고(탱크 가로 폭이 기기 화면 비율에 맞춰짐), 펌프 버튼은 좌·우 아래 구석의 작은 아쿠아 버튼입니다. 시작할 때 잡은 방향으로 게임 화면을 기기에 고정해서, 기울이다가 OS가 화면을 자동 회전해도 게임 화면은 그대로입니다(Android는 첫 탭에서 전체화면 + 가로 잠금)
- **조작**: 좌/우 펌프 버튼 (짧게 톡 = 약한 물살, 길게 꾹 = 강한 물살). 키보드 ←/A, →/L
- **중력 센서**: 실제 워터링 게임기처럼 폰 자체를 움직여 링을 조작합니다. ① 폰을 돌리면(기울이면) 실제 중력 방향이 바뀌어 링이 그쪽으로 미끄러지고(각도 1.8배 증폭), ② 앞뒤로 휙 젖히면 물이 출렁이며 링이 위/아래로 밀렸다가 돌아오고, ③ 폰을 위아래·좌우로 흔들면 관성으로 링이 반대쪽으로 튑니다. 기준 자세 설정이 필요 없습니다. 탱크 오른쪽 위 수평계에 현재 중력 치우침이 표시됩니다. G 버튼으로 켜고 끕니다(초록 = 센서 신호 수신 중, 노랑 = 아직 신호 없음 + 이유 표시). 권한이 필요한 브라우저(iOS 등)는 화면을 처음 탭할 때 요청하며, 자이로가 없는 폰은 가속도계 값으로 대신 계산합니다. HTTPS에서만 동작
- **모드**: 클래식(30스테이지, 최소 펌프 기록·별 3개), 타임어택(60초), 컬러 매칭(10스테이지, 다른 색 기둥은 링을 튕겨냄), 데일리 챌린지(날짜 시드 배치)
- **방해 요소**: 물고기, 거품 기둥, 소용돌이, 움직이는 기둥, 문어 보스(기둥 끝을 가렸다 열었다) / 보너스: 황금 링(2배), 한 기둥 콤보
- **스킨**: 케이스 4종 · 링 5종 · 배경 4종, 클래식+컬러에서 모은 별로 해금
- **물리**: 링 = 양 끝 두 점(튜브 단면)만 충돌하는 강체 → 기둥이 구멍을 통과. 바닥은 노즐 쪽으로 기울어져 링이 물살 위로 모이고, 물살이 닿지 않는 곳에 갇힌 링은 기포가 밀어 올림
- 글로벌 랭킹·광고/결제는 서버가 필요하여 미구현 (기록은 로컬 저장)

## 플래닛 보블 (Planet Bobble)

1994년 타이토 퍼즐버블(Puzzle Bobble) 복각. 버블 대신 태양계 행성 8종(수성·금성·지구·화성·목성·토성·천왕성·해왕성)을 쏩니다. 행성은 모두 같은 크기이고, 토성은 고리까지 같은 원 안에 들어가도록 그립니다.

- **조작 (센서)**: 휴대폰을 좌우로 돌린 각도만큼 발사 방향이 움직입니다(기본 1:1, `SENS` 버튼으로 1.5×/2×). 휴대폰 윗부분을 뒤로 휙 젖히면 발사합니다. 천천히 기울이는 건 발사로 치지 않고(약 50°/s 이상이어야 함), 발사 각도는 젖히기 직전의 조준값을 써서 손목 동작 때문에 조준이 틀어지지 않습니다. 시작할 때 카운트다운 동안 잡은 자세가 기준(0°)이 되고, `⟲ CENTER`로 다시 맞출 수 있습니다. 하단 막대는 젖히기 진행도입니다
- **대체 조작**: 센서가 없으면 터치/마우스로 조준한 뒤 떼면 발사, 키보드는 ←/→ 조준 + Space 발사, P 일시정지
- **떨어뜨리기**: 같은 행성 3개 이상이면 펑(개당 10점). 천장과 끊어진 덩어리는 한꺼번에 떨어지고 점수는 `10 × 2^개수`(20, 40, 80 … 최대 17개분). 떨어지는 행성은 흔들리다 빠져서 벽에 튕기며 화면 아래 "이벤트 호라이즌"으로 빨려 들어가고, 하나씩 들어갈 때마다 점수가 두 배로 올라가며 음이 높아집니다. 개수에 따라 DROP! → GREAT DROP! → COSMIC FALL! → SUPERNOVA!! 연출(흔들림·섬광·화음)이 커집니다
- **뱅크샷**: 조준선은 첫 번째 벽 반사 지점까지만 표시합니다(그 전에 행성에 닿으면 거기까지). 반사 이후 궤적은 직접 읽어야 합니다
- **천장 압박**: 일정 발사 횟수마다 천장이 한 줄 내려옵니다. 남은 횟수는 천장 판의 불빛과 발사대 오른쪽 숫자 링으로 표시되고, 2발 남으면 노랑, 1발 남으면 빨강 깜빡임 + 경고음 + 매달린 행성 전체가 떨립니다. 행성이 빨간 점선을 넘으면 게임 오버
- **레벨**: 30레벨(색 4 → 8종, 천장 주기 9 → 5발). 클리어하면 다음 레벨이 열리고, 클리어 보너스 = 1000 + (40 − 발사 수) × 50

## 수박 게임 (Suika)

같은 과일 두 개가 닿으면 다음 단계 과일로 합쳐지는 머지 퍼즐. 체리 → 딸기 → 포도 → 한라봉 → 감 → 사과 → 배 → 복숭아 → 파인애플 → 멜론 → 수박 순서로 커집니다. 과일은 모두 Canvas로 직접 그립니다(이미지 자산 없음).

- **조작 (센서)**: 휴대폰을 좌우로 기울인 각도만큼 과일(구름 드로퍼)이 옆으로 이동합니다. 기본은 30° 기울이면 벽 끝까지(`SENS` 1.5× = 20°, 2× = 15°). 휴대폰 윗부분을 뒤로 휙 젖히면 과일을 떨어뜨립니다(플래닛 보블과 같은 플릭 감지 — 천천히 기울이는 건 무시, 떨어뜨리는 위치는 젖히기 직전 위치). 카운트다운 동안 잡은 자세가 기준(0°)이고 `⟲ CENTER`로 다시 맞춥니다. 하단 막대는 젖히기 진행도
- **대체 조작**: 센서가 없으면 터치 드래그 후 떼면 낙하, 키보드는 ←/→ 이동 + Space/↓ 낙하, P 일시정지
- **규칙**: 떨어지는 과일은 작은 5종(체리~감) 중 랜덤, 오른쪽 위에 NEXT 표시. 과일이 만들어질 때마다 점수(딸기 3 … 수박 66), 수박 두 개가 합쳐지면 사라지며 +100. 착지한 과일이 상자 위 빨간 선을 넘은 상태로 약 2초가 지나면 게임 오버(선 근처에 쌓이면 점선이 나타나고, 넘으면 깜빡임 + 경고음)
- **물리**: 외부 엔진 없이 위치 기반 동역학(프레임당 8 서브스텝 × 3회 겹침 해소, 크기² 질량비, 접선 마찰, 굴러가는 회전). 합쳐진 과일은 작게 시작해 커지면서 주변 과일을 밀어냅니다
